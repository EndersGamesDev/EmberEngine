# UltimateLegue models

This directory separates the versioned model and environment outputs used by UltimateLegue builds.

The League client and its offline art tools depend on these GLBs and manifests; each version folder names whether it contains champion, prop or surface outputs.

Generation and review follow the League tooling under `tools/league/` together with the format and renderer constraints in [`docs/asset-pipeline.md`](../../../docs/asset-pipeline.md).
