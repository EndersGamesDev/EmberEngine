# Version 1 material and model assets

The models were generated by the user's local SDXL/TRELLIS asset workflow and converted for Ember: GLB, one primitive, one embedded 8-bit base-color image, Y-up, nominal +X facing, floor-centered origin. `sword.glb` instead uses its grip as origin and points along +X. `runtime-manifest.json` records exported dimensions and counts. Cot length runs Z; the imported sleeping warden includes its seated pose.

`oak.png`, `stone.png` and `iron.png` are deterministic 1024² RGB material maps, generated by `tools/end-game/generate_surfaces.py`. The scene shares each map among surfaces and assigns each face seeded UV offsets; this creates local variation without allocating a whole texture for every brick. No texture is advertised as a unique 5K scan. Textured objects use neutral white instance tint; roughness and metal content are scalar engine surface values.

The source's disconnected geometry is voxel-reconstructed and reduced, then diffuse color is rebaked onto new UVs with padded gutters. Wolf and cot receive a thin closed shell before reconstruction. The seven final models total 6,944,580 bytes and 54,000 triangles; all embedded textures are 768 square. Fine hand/chair/flame fragments remain generator limitations. Native rendering confirmed the repaired warden's solid coverage.

Armor uses prototype spatial zones for iron, leather belt and cloth cape; authored material IDs and cloth simulation are follow-ups.
