# End Game runtime assets

Versioned optimized exports of the End Game asset set. The original artist/generator source remains in the separate `end-game` workspace. `v1/` retains characters, weapons and original props; `v2/` adds generated cell materials and detailed furnishings; `v3/` adds articulated gauntlets, item sockets, the iron key and a properly sized greatsword hilt; `v5/` adds an articulated warden, stationary chair and grip-mounted knife. Each version documents its rendering contract and provenance.
