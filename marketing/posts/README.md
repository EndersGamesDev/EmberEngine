# Launch post drafts

This directory contains channel-specific launch copy for Reddit, Hacker News, social threads and video narration.

The marketing plan and human publishers depend on these drafts as reviewable source material; posting itself requires the appropriate external account and is not performed by repository automation.

Channel status and evidence live in [`../LOG.md`](../LOG.md) and [`../BOARD.md`](../BOARD.md), while hand-offs follow [`docs/worker-protocol.md`](../../docs/worker-protocol.md).
