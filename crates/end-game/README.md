# End Game

Version 5.0.0, The Warden’s Knife, is a single-player dark fantasy dungeon built on Ember. The chapter begins in a prison cell and ends after the player retrieves the greatsword and breaks the far gate's chain. Rules and material physics live in `end-game-core`; this client owns scene construction, input translation, the camera and presentation.

Build the browser game from PowerShell with `& ./tools/end-game/build.ps1` at the repository root, then serve `web/` and open `games/end-game/v5/`. Run the native client with `cargo run -p end-game --bin end-game-app`. Builds run at Idle priority through the helper. Native player launches take focus; unattended captures use `EMBER_CAPTURE_PATH` and disable activation and input capture.

The game is a vertical slice. Shapes are assembled from material-based parts with seeded per-face surface coordinates, gravity and friction. The renderer supports scalar roughness/metallicity, local inverse-square torch lights, directional shadows, alpha dust/embers and adaptive browser resolution. This is not a path-traced renderer or a measured photorealistic 5K result. V3 first-person arms use 34 named rigid parts, finger curl and thumb opposition, Ember arm IK, and item grip sockets. Full-body imported hero meshes remain unrigged; armor evolution swaps forms under a close camera and particles. The supplied film is a prerecorded prologue, including the dragon encounter, and retains the original asset set's continuity limitations.

Input: WASD/mouse, E interact, left click strike, Space jump, Alt dodge, C crouch, Shift sprint, Q form, V camera. Standard-mapped controllers use left/right sticks, Square interact, R2/R1 strike, Cross jump, Circle dodge, L1 crouch, L3 sprint, Triangle form, R3 camera and Options pause. Touch has a left stick, right look area and six action buttons. Gamepad haptics are best-effort browser dual-rumble, not DualSense adaptive-trigger effects.

`hands.rs` evaluates reach/grasp/lift/recovery from fixed-step interaction time. Board movement, key ownership and gate movement are delayed until contact in the authored sequence. The camera and shoulders crouch together, approaches are collision checked, and competing input edges are discarded during pickups. V4 retains the V3 articulated meshes, finger presets and item sockets; `sword_motion.rs` supplies distinct Cut, Backhand, Finisher, Overhead and Rising arcs while both hands stay attached to the sword grips.

Combat accepts press edges and buffers valid follow-ups through the active strike's recovery. One tap performs Cut. Wolf's Fang uses three quick taps for Cut → Backhand → Finisher; Gravebreaker uses tap, pause, tap for Cut → Overhead; Rising Wolf uses tap, tap, pause, tap for Cut → Backhand → Rising. Quick gaps are at most 0.30 seconds; delayed gaps are greater than 0.30 and at most 0.90 seconds between consecutive presses. Holding attack does not repeat. The simulation evaluates damage at contact time; confirmed hits drive hitstop, camera/weapon recoil and impact feedback.

Native capture presets `lift-board`, `pickup-key`, `unlock` and `draw-sword` accept `END_GAME_ACTION_TIME` in seconds; `END_GAME_TIME` controls environmental motion. The `combat` preset additionally accepts `END_GAME_STRIKE=cut|backhand|finisher|overhead|rising`, with `END_GAME_ACTION_TIME` defaulting to the chosen strike's contact time. Optional `END_GAME_IMPACT=1` stages impact presentation for inspection. Set `EMBER_CAPTURE_PATH` to use the passive one-frame capture path. Tests cover authored contacts, arm lengths, look limits, pause and input transitions; capture presets provide inspection tools rather than evidence that a visual or gameplay check has passed.

V5 replaces the fused seated warden with named articulated body parts, a separate chair and a hand-attached knife. `warden.rs` presents wake-up, planted-foot rising, knife draw, pursuit, attack, stagger and death from `warden_ai` simulation state. The knife stays on the right-hand socket; the old V1 asset remains available to frozen releases. Enemy windups and successful hits are exposed to the browser shell independently of its slower text refresh.

Passive native `END_GAME_SCENE=warden` accepts `END_GAME_WARDEN_PHASE=sleeping|waking|hunting|attacking|staggered|dead`, `END_GAME_ACTION_TIME` in seconds and optional `END_GAME_WALK_PHASE`. `END_GAME_WARDEN_DISTANCE` selects a 1–3 metre camera distance, defaulting to 2.8 metres. These stage an inspection pose and never synthesize machine input. `EMBER_CAPTURE_PATH` still selects the scene PNG and exit behavior.

For interrupted knife poses, set `END_GAME_WARDEN_INTERRUPT_TIME` to the attack time in seconds and select `staggered` or `dead`; `END_GAME_ACTION_TIME` then measures time since the hit. The native fixture uses the same sword-hit transition as gameplay.
