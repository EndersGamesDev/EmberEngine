# End Game releases

`v9/` contains Beyond the Dungeon, with a connected great hall, garden, battlements and climbable tower. V8 retains Edge and Guard, V7 The Dread Warden, V6 The Warden’s Voice, V5 The Warden’s Knife, V4 Weight of the Blade, V3 Hands of the Wolf, V2 The Living Cell and V1 The Awakening. Each source release has a matching `codex/end-game-vN` branch. Scoped assembly writes V9 and preserves the complete V1–V8 releases. All versions run on Ember. The launcher selects its live entry using `web/games.json`; each served `version.json` records source and file hashes.
