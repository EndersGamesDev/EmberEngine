# End Game web releases

`v2/` contains The Living Cell's current browser shell and version-local media. `v1/` retains The Awakening's original page; its published WASM is frozen on GitHub Pages, with buildable source retained on `codex/end-game-v1` at `9f4acfbf`. Both releases run on Ember. The launcher selects the live release using `web/games.json`.
