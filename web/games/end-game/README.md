# End Game releases

`v12/` contains Parry and Impact, where tapping guard opens a timed window that deflects a strike instead of blocking it. V11 retains Weight and Impact, V10 The Last Seal, V9 Beyond the Dungeon, V8 Edge and Guard, V7 The Dread Warden, V6 The Warden’s Voice, V5 The Warden’s Knife, V4 Weight of the Blade, V3 Hands of the Wolf, V2 The Living Cell and V1 The Awakening. Each source release has a matching `codex/end-game-vN` branch. Scoped assembly writes V12 and preserves the complete V1–V11 releases. All versions run on Ember. The launcher selects its live entry using `web/games.json`; each served `version.json` records source and file hashes.
