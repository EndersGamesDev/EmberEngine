# End Game releases

`v8/` contains Edge and Guard, with edge-leading cuts, connected combos and directional sword blocking. V7 retains The Dread Warden, V6 The Warden’s Voice, V5 The Warden’s Knife, V4 Weight of the Blade, V3 Hands of the Wolf, V2 The Living Cell and V1 The Awakening. Each source release has a matching `codex/end-game-vN` branch. Scoped assembly writes V8 and preserves the complete V1–V7 releases. All versions run on Ember. The launcher selects its live entry using `web/games.json`; each served `version.json` records source and file hashes.
