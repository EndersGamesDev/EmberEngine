# End Game web releases

`v4/` contains Weight of the Blade's browser shell: heavy two-handed strikes, queued tap rhythms, contact-timed damage, hitstop and recovery using the V3 articulated hand assets. `v3/` retains Hands of the Wolf and its item interactions. `v2/` retains The Living Cell, with buildable source on `codex/end-game-v2` at `48a37a71`; `v1/` retains The Awakening, with source on `codex/end-game-v1` at `9f4acfbf`. Scoped release assembly writes V4 and preserves existing V1, V2 and V3 pages and bundles. All releases run on Ember. The launcher selects the live release using `web/games.json`; the presence of a version directory alone does not establish publication status.
