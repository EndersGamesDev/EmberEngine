# End Game web releases

`v7/` contains The Dread Warden, with a generated textured enemy and grounded motion. `v6/` retains The Warden’s Voice, `v5/` retains The Warden’s Knife, `v4/` retains Weight of the Blade, `v3/` retains Hands of the Wolf, `v2/` retains The Living Cell and `v1/` retains The Awakening. Each source release has a matching `codex/end-game-vN` branch. Scoped assembly writes V7 and preserves existing V1–V6 pages and bundles. All releases run on Ember. The launcher selects the live release using `web/games.json`; publication source and file hashes are recorded in each release’s served `version.json`.
