# End Game web releases

`v3/` contains Hands of the Wolf's current browser shell and version-local media. `v2/` retains The Living Cell, with buildable source on `codex/end-game-v2` at `48a37a71`; `v1/` retains The Awakening, with source on `codex/end-game-v1` at `9f4acfbf`. Their published WASM bundles remain frozen on GitHub Pages. All releases run on Ember. The launcher selects the live release using `web/games.json`.
