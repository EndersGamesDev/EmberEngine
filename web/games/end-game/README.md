# End Game web releases

`v5/` contains The Warden’s Knife, with an articulated rising and knife-fighting enemy. `v4/` retains Weight of the Blade, `v3/` retains Hands of the Wolf, `v2/` retains The Living Cell and `v1/` retains The Awakening. Each source release has a matching `codex/end-game-vN` branch. Scoped assembly writes V5 and preserves existing V1–V4 pages and bundles. All releases run on Ember. The launcher selects the live release using `web/games.json`; publication source and file hashes are recorded in each release’s served `version.json`.
