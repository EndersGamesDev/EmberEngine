# End Game 2.0.0 — The Living Cell

Version-local browser shell for the detailed prison-cell chapter. Build `end-game` with `tools/end-game/build.ps1`, serve `web/`, and open this directory. The browser loads the version-local Ember WASM bundle. This release retains keyboard/mouse, gamepad and touch controls and adaptive resolution. The v1 page and deployed bundle remain frozen at their existing address.

V2 adds generated stone and timber surfaces, more detailed masonry and furnishings, a recessed barred window, layered ironwork, animated gate/loose board, moving chains, cloth and water. Gameplay remains the first chapter's escape. Physical controller/mobile testing and browser gameplay are separate from native capture and simulation verification.
