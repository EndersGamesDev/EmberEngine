# Fire Racer pages

This directory holds the archived first Fire Racer page and the live castle-circuit release page.

The launcher maps both versions through [`../../games.json`](../../games.json), while Pages deployment rebuilds only the declared live version with the Fire wasm bundle.

Release and frozen-page rules live in [`docs/versioning.md`](../../../docs/versioning.md), and the assembly contract lives in [`deploy/deploy-pages.sh`](../../../deploy/deploy-pages.sh).
