# Four Kings pages

This directory owns the browser entry point for the Four Kings game family.

The launcher selects its version through [`../../games.json`](../../games.json), and Pages deployment pairs the live page with the generated Kings wasm bundle.

Game rules live in [`docs/kings-design.md`](../../../docs/kings-design.md), while publication and tag rules live in [`docs/versioning.md`](../../../docs/versioning.md).
