# Killshot landing media

The pictures and the film used by [`../index.html`](../index.html). These are published bytes: every file here is downloaded by anyone who opens the landing page, so each one earns its size.

| File | What it is |
|---|---|
| `trailer.mp4` | The trailer. H.264 video, AAC audio, 1280×720 at 30 fps, `+faststart` so it begins playing before it has finished downloading. |
| `trailer.vtt` | English captions for the narration, generated from the mix's own cue list (`cues.json`) rather than written by hand, so a recut cannot drift them. |
| `trailer-poster.jpg` | The video's poster frame: a real frame of the v31 client, not artwork. The video is `preload="none"`, so this image is all a visitor downloads until they press play. |
| `hero.jpg` | The hero background. Generated concept art, not a screenshot — the page says so where it matters, and the poster and the trailer carry the real thing. |

## Provenance

The trailer's gameplay is recorded from the real v31 client running in a browser against a private server, by [`tools/trailer/capture-gameplay.cjs`](../../../../tools/trailer/capture-gameplay.cjs). The cinematic shots between the gameplay, the hero image, the music and the narrator's voice are generated by the LAN asset workers; the narration was written against `crates/arena-core` and states only what the game does. [`tools/trailer/README.md`](../../../../tools/trailer/README.md) is the full recipe.

Because the two sources look different on purpose, the page's caption under the video says which is which. Do not remove that line while the generated shots are in the cut.
