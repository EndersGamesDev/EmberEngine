Descriptor-heap effect on WebGL2

One immutable heap bind group, integer handles, two finite texture arrays, and no bindless claim. Every step renders immediately; mapped-fence measurement is opportunistic, cancellable, and reported separately from capacity arithmetic.

Benchmark A · heap-fetch overhead

Each base invocation shades a 512×512 RGBA8 target and performs 16 dependent nearest RGBA32F loads per fragment: 4,194,304 payload loads. Direct binds one 64×64 texture; heap reads descriptor 1, maps the same coordinates, and loads a DATA array layer.

Runtime walls and lowering facts

loading versioned wasm…
Primary timing is CPU encode/write plus queue submit through an ordered four-byte MAP_READ fence. The WebGL2 backend explicitly calls device.poll(Poll) in a zero-timeout yield loop; Benchmark A waits expire after 4,000 ms and Benchmark B waits after 30,000 ms. Benchmark A uses three warmups and 15 adaptive samples. Benchmark B first measures exactly one frame: above the 100 ms animation threshold it keeps that one single-frame-on-demand observation, while faster steps continue through three warmups and 15 samples that each span at least 32 measured performance.now() quanta. Median, p95, and per-draw microseconds are visible-run observations, not admission gates. GPU timestamp results remain absent unless the selected backend path actually uses an exposed query feature.
