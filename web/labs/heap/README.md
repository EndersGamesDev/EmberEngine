# GPU heap lab

This directory contains the current equal-rung heap-lattice comparison, the output-path golden spike and the archived descriptor-fetch and draw-call benchmarks.

Renderer design and minimum-device reviewers depend on these standalone WebGL2 pages as executable evidence for resource-heap choices.

Interpret the experiments through [`docs/gpu-resource-heap.md`](../../../docs/gpu-resource-heap.md), [`docs/gpu-heap-lattice.md`](../../../docs/gpu-heap-lattice.md) and the conformance role recorded in [`docs/minimum-requirements.md`](../../../docs/minimum-requirements.md).
