# Live Julibrot lab

This directory contains the Julibrot page, controls, module graph, worker, controls-free driver and frozen whole-grid oracle data for the four-dimensional slice viewer.

The launcher links this lab through [`../../games.json`](../../games.json), crate page-contract tests include these sources directly, and Pages deployment adds the generated Julibrot wasm package while shipping the proof driver.

Start with [`docs/julibrot-lab.md`](../../../docs/julibrot-lab.md), then use [`docs/julibrot/`](../../../docs/julibrot/) for component contracts and [`docs/minimum-requirements.md`](../../../docs/minimum-requirements.md) for the WebGL2 floor.
