# Browser labs

This directory contains browser-facing experiments for GPU heap access, higher-dimensional fragment-generated lattices and the live Julibrot slice viewer.

Engine researchers and reviewers depend on these pages as observable demonstrations and measurement surfaces; only Julibrot is currently listed in the launcher catalogue.

Each lab README names its design record and runtime floor, with repository-wide renderer constraints in [`CLAUDE.md`](../../CLAUDE.md) and publication behavior in [`deploy/deploy-pages.sh`](../../deploy/deploy-pages.sh).
