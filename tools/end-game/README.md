# End Game tooling

`build.ps1` runs the game-specific Rust, resolution, dialogue and guard checks, copies the four V6 voice clips plus the V10 castle voices and ambience, and produces the Ember WASM bundle and web bindings for V12, Parry and Impact. Optional `-TargetDir` selects an existing Cargo cache. `publish.py` assembles only End Game’s V12 files and updates its live catalog entry, preserving every other game, host book, landing-page change and the complete V1–V11 releases. It defaults to staging; `--publish` sends a normal fast-forward push to GitHub Pages. The staging directory is retained for inspection. `publish_test.py` checks scoped assembly offline, including byte preservation of frozen V1–V11 pages, media, version stamps and bundles.

`quality.test.mjs` verifies pixel caps and overload behavior. `generate_surfaces.py` creates the three deterministic material maps using numpy and Pillow; pass an output directory as the first argument. Runtime mesh provenance is recorded alongside the assets.

V2 prop reproduction uses `v2_generate_prop_textures.py`, `v2_build_props.py` (Blender background mode), then `v2_finalize_props.py`. Set `END_GAME_V2_ASSET_WORK` to a scratch directory with a `props/` subdirectory and place the generated oak original at `surfaces/oak-aged-albedo-v2.png`; the original selected image is also committed as `assets/end-game/v2/oak.png`. The generators write only under that scratch directory. Final RGB8 JPEG atlases retain the original editable PNGs and Blender files outside source control. Their bounds, animation pivots and payload hashes are in `assets/end-game/v2/props-manifest.json`.

Unattended native capture: set `EMBER_CAPTURE_PATH` to an output PNG and optionally `END_GAME_SCENE` to `cell`, `cell-detail`, `cell-wall`, `corridor`, `sword` or `wolf`, then run `end-game-app`. This captures only Ember's scene texture, never the desktop, and the game disables focus activation, input capture and simulation. Native capture exits after one rendered frame. Optional `END_GAME_TIME` freezes environmental animation at an exact simulation time for before/after comparisons. V2 albedo prompts and generated prop provenance are recorded under `assets/end-game/v2/`. The engine's GPU regression tests can run without any window: `cargo test -p ember-engine environment_gpu -- --ignored`.

To reproduce meshes, set END_GAME_ASSET_WORK to an empty scratch directory; run prepare_textures.py with the original End Game asset root as its argument, then run repair_assets.py in Blender background mode with four threads at Idle priority, and verify_repaired.py in Python with numpy, Pillow and scipy. The scripts reconstruct geometry, generate UVs, rebake diffuse color, pad atlas gutters, and validate texture format and mesh connectivity. Source assets are read only.

V3 gauntlets use `v3_generate_atlas.py` then Blender `v3_build_hands.py`; the same geometry library feeds `v3_build_sword.py`. Set `END_GAME_V3_ASSET_WORK` to the scratch output directory. The GLB parts, RGB8 atlases, named pivots, finger presets and item sockets are described in `assets/end-game/v3/`. Native presets `lift-board`, `pickup-key`, `unlock` and `draw-sword` accept `END_GAME_ACTION_TIME` in seconds to inspect contact and recovery without machine input.

V4 retains those articulated assets and adds five sword motions driven by `end-game-core` combat time. One tap selects Cut. Three quick taps select Wolf's Fang (Cut → Backhand → Finisher); tap, pause, tap selects Gravebreaker (Cut → Overhead); tap, tap, pause, tap selects Rising Wolf (Cut → Backhand → Rising). A quick gap is at most 0.30 seconds; a delayed gap is greater than 0.30 and at most 0.90 seconds. Valid follow-ups queue during the active strike. Damage and impact feedback occur at confirmed contact, followed by hitstop and recovery.

Use `END_GAME_SCENE=combat` with `EMBER_CAPTURE_PATH` for a frozen native sword pose. `END_GAME_STRIKE` accepts `cut`, `backhand`, `finisher`, `overhead`, `rising` or `jump-heavy`; missing or unknown values select Cut. `END_GAME_ACTION_TIME` is elapsed strike time in seconds, defaults to the selected strike's contact time, and clamps to its duration. Optional `END_GAME_IMPACT=1` stages the impact effect for inspection without demonstrating collision or damage. `END_GAME_TIME` independently controls environmental animation. These captures use the same passive, one-frame path described above and require no mouse, keyboard or foreground interaction.

V12 also accepts `END_GAME_SCENE=sword-hit` to run a bounded core strike before passive capture. `END_GAME_HIT_TARGET=enemy|wall|floor|iron` selects the fixture; enemy is the default. `END_GAME_ENEMY_KIND=soldier|spear|hollow|cyclops`, `END_GAME_TARGET_ZONE=head|left-torso|right-torso|left-leg|right-leg`, `END_GAME_ENEMY_DISTANCE` and `END_GAME_X/Y/Z/YAW/PITCH` configure the contact approach. Aim is a setup hint; the first blade contact determines the actual zone, reported with the persistent reaction in stderr. `END_GAME_AFTER_HIT_FRAMES` advances 0–120 ticks after first impact, default 12. `END_GAME_VIEW_MARK=1` then frames the latest surface mark. `END_GAME_CROUCHED=1`, `END_GAME_THIRD_PERSON=1` and `END_GAME_AIR_HEIGHT` provide stance/camera variants. The pose-only `combat` preset additionally accepts `END_GAME_LANDING_WAIT=1` for airborne follow-through. These options are native capture fixtures and do not alter browser gameplay.

V5 native inspection uses `END_GAME_SCENE=warden`, `END_GAME_WARDEN_PHASE=sleeping|waking|hunting|attacking|staggered|dead`, and `END_GAME_ACTION_TIME`. `END_GAME_WALK_PHASE` selects a walk-cycle phase; `END_GAME_WARDEN_DISTANCE` selects a 1–3 metre camera distance. These passive snapshots stage presentation only; fixed-step tests establish attack and collision behavior. The original V5 source asset generation and shared pivot contracts are recorded under `assets/end-game/v5/`.

V6 audio reproduction uses `v6_generate_voice.py` on the cached CPU Kokoro worker, then `v6_finish_voice.py` locally and `v6_verify_voice.py` for offline signal and source-transcript checks. `v6_check_dictation.ps1` is an optional file-input-only diagnostic using the installed Windows English recognizer. The asset README records provenance and exact reproduction. `dialogue.test.mjs` verifies playback priority, per-life deduplication, pause/resume, mute, missing audio, completion and cue durations against the actual WAVs.

V7 passive character inspection adds side/back camera views, a configurable downward pitch and explicit gait blending through `END_GAME_WARDEN_VIEW`, `END_GAME_WARDEN_PITCH` and `END_GAME_WALK_BLEND`. See the client README for ranges. The generated jailer’s conversion and source job records are documented under `assets/end-game/v7/`. V6 dialogue tests and speech remain part of the V7 build and publication.

V8 adds `guard.test.mjs` for held-button cancellation, pause/focus release and per-frame block feedback. Native `END_GAME_SCENE=guard` exposes raise, held, lower, recoil and break poses through `END_GAME_GUARD_PHASE` and `END_GAME_ACTION_TIME`. Sword-motion tests check edge-leading contacts, continuous combo transitions, failed-link recovery and reachable two-hand grips. Reference and gameplay rules are in `docs/end-game-combat.md`.

`castle.test.mjs` checks castle event history, voice interruption, pause timing, caption fallback and discovered-clue presentation. `tools/end-game/v10/` contains the generated enemy and audio reproduction pipeline. The V10 castle route and mechanics are described in `docs/end-game-castle.md`.

V12 keeps the V11 blade sweep, five-zone contact, directional reactions and bounded surface marks, and adds the timed parry: tapping guard opens a 0.12-second window that deflects a strike for 22 stamina and staggers its owner, while sword soldiers and the Castellan turn a player's cut aside during their own windup. The normal three-cut chain uses upper-right-to-lower-left, left-to-right and steeper descending directions. Separate heavy inputs are R/middle click, R2 or Heavy; jump first for a downward airborne cut followed by a held follow-through until landing, with no second landing damage. Rules and remaining anatomical/prop proxy limits are documented in `docs/end-game-combat.md`.

`guard.test.mjs` now executes the actual V12 shell with passive DOM/API/audio graph doubles: normal/heavy input, nonrepeat behavior, guard/pause/ending suppression, five-zone intent versus confirmed impact, airborne cut versus landing hold, material sound routing, aspect-correct `aimProjection` reticle placement, and the parry window, deflection ring and cooldown as distinct from a block. Invalid/offscreen aim is hidden rather than clamped into a false target. These Node checks synthesize no workstation input and perform no browser rendering or audible playback. Native snapshots and fixed-step collision tests remain separate evidence; static capture presets alone do not establish damage, physical-device support or frame pacing.
