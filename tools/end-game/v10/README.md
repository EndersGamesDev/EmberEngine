# End Game V10 asset reproduction

Use an explicit scratch directory outside the checkout. Raw source GLBs, images, intermediate bakes and previews are not runtime assets. The existing workflow requires the already installed asset-forge CLI, Blender, NumPy/SciPy/Pillow Python environment and the cached Adler Kokoro environment; it does not install or reconfigure workers.

Set `ASSET_FORGE_CLI` to the existing `asset_cli.py` path on your workstation. The generation helper's fallback is the original workstation path `C:/Users/end/dev/cluster/provision/asset-forge/asset_cli.py`; this external CLI is not bundled in Ember. Runtime output defaults are resolved relative to these scripts inside the repository. Use `EMBER_ROOT` for a different checkout or when copying scripts into scratch, and `END_GAME_V10_OUT` for a separate output directory.

Set `END_GAME_V10_WORK` to the scratch root for `generate_characters.py`, `verify_characters.py`, `finish_audio.py` and `build_weapons.py`. `generate_characters.py CHARACTER STAGE` supports soldier, hollow-knight and cyclops, and image/cutout/mesh stages; cutout and mesh need `--input`. Read fresh Barza reservations, post a bounded claim and confirm each worker queue is empty before generation. Release the claim when jobs finish.

For Blender conversion, set `END_GAME_V10_WORK` to the character subdirectory, `END_GAME_V10_CHARACTER` to its name, `END_GAME_V10_SOURCE` to its raw GLB and `EMBER_ROOT` to the engine checkout. Copy `rig-source-config.json` to the scratch root. Run `convert_character.py` in background Blender at Idle priority with two CPU threads. The converter makes closed convex retopology for each segmented part, projects generated facial relief onto the head, adds inner leg/joint coverage, rebakes compact RGB8 atlases and adapts the source joints to the runtime bind. It preserves the generated material and broad silhouette while simplifying concavities and fused fingers. Cyclops classification uses its full low hand extent and bounded hips, and its authored dark central eye sits beneath the generated brow. Inspect the exported standing preview and run `verify_characters.py CHARACTER` from the scratch root before installation.

`build_weapons.py` authors measured, grip-centered weapon GLBs with a seeded compact atlas. `generate_voice.py --out PATH` runs on the existing Adler CPU environment `/home/ender/asset-forge/envs/tts/bin/python`, with the already cached Kokoro revision, offline mode, two threads and nice 19. Copy the raw WAVs and generation JSON into the scratch root's `raw` directory; `finish_audio.py` writes the five speech WAVs, manifest, JavaScript event contract and authored ambient loop. `END_GAME_V10_OUT` overrides the runtime output folder for audio and weapons.

`verify_characters.py` checks decoded exported files rather than Blender scene counts: names, identity transforms, attributes, indices, triangles, opaque RGB8 materials, cloned texture/mip budgets and actual central torso surface coverage. Keep generated provenance and check native animation separately. Passive previews and numeric checks do not establish browser gameplay, device audio, controller vibration or frame pacing.
