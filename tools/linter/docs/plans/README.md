# Linter plans

This folder records unfinished linter work: the general backlog, closure of the declared-surface migration, and the design used to repair the repository-isolation boundary.

The plans guide changes to `tools/linter`, its tests, and `.linter` declarations but do not supersede accepted decisions; completed behavior is consumed through the library and command-line entry points.

Current authority remains in `tools/linter/adr`, its register in the parent `docs` directory, and the crate contract in `tools/linter/README.md`.
