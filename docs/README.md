# Documentation

This directory holds ember's architecture, protocol, operations, asset, game-design and active planning documents; start with the repository [README](../README.md), then open only the document relevant to the work at hand.

Engine, game, deployment and review work depends on these documents as the durable explanation of constraints that would be too detailed for [`CLAUDE.md`](../CLAUDE.md).

Repository-wide working rules live in [`CLAUDE.md`](../CLAUDE.md), branch integration and release promotion rules live in [`branching.md`](branching.md), pull-request bodies and landing steps live in [`pull-requests.md`](pull-requests.md), coordination rules live in [`worker-protocol.md`](worker-protocol.md), version and tag rules live in [`versioning.md`](versioning.md), commit rules live in [`commit-messages.md`](commit-messages.md), and folder documentation rules live in [`readmes.md`](readmes.md).

The [`julibrot/`](julibrot/) directory documents that lab's implementation, while [`plans/`](plans/) holds active designs and the shared backlog rather than finished-work summaries.
